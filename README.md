# MyVehicle

## Android Vehicle Maintenance Management Application

MyVehicle is an Android application designed to help vehicle owners manage vehicle information, track maintenance services, and review maintenance expenses.

The application provides a convenient way to organize multiple vehicles and maintain their service histories.

## Features

- Add, view, update, delete, and search vehicle records.
- Record and manage vehicle maintenance services.
- Search maintenance history.
- Track maintenance costs.
- Generate maintenance reports.
- Store vehicle and service information locally using Room Database.
- Access the application through a login screen.

## System Requirements

- Android 8.0 (Oreo) or later.
- Android device or compatible Android emulator.
- Approximately 25 MB of available device storage recommended for installation and locally stored application data.

## Data Storage

MyVehicle uses a local Room database to store vehicle and maintenance information on the Android device.

No cloud database connection is required.

Application data remains on the device unless it is deleted through the application or the device's application storage is cleared.
